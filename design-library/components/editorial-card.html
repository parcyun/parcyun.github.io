Claude Desktop을 자율형 에이전트로 직접 셋업하고 운영해보는 실습 가이드.

Claude Desktop 실습

Usage

1. .editorial-card 블록 + Tag Pill CSS 복사
2. poster .lid (라벨) + .ptitle (시리즈 타이틀, strong 강조)
3. body .meta · .title · .desc · .tags 교체

POSTER (이미지 없이 타이포만으로 시선 잡는 영역):
- aspect-ratio 370:220
- 좌상단: 캡스 라벨 (시리즈명·번호·카테고리)
- 좌하단: 큰 한글 타이틀 + amber strong 한 단어
- 배경: 미세한 amber radial gradient 2개로 깊이감

BODY:
- meta: 캡스 + dot 구분자 (날짜·길이·대상)
- title: 한글 본 제목 + 영문 부제 ("·"로 구분)
- desc: 1-2 문장
- tags: TagPill 3개 이내

WHEN TO USE:
- 강의·작품·콘텐츠 카드 그리드 (1108px max width 기준 3-col)
- 시리즈물 카탈로그
- 포트폴리오 작품 카드

WHEN NOT TO USE:
- 단일 카드 (대신 큰 hero 사용)
- 이미지가 필수인 콘텐츠 (사진 카드는 별도 패턴)
- 5개 이상 빈번한 업데이트 (오히려 단순 리스트가 효율적)

VARIANT IDEAS:
- 호버 시 poster 영역 amber 강조 추가 가능
- lid을 amber 대신 카테고리별 다른 색상 사용 가능 (Cinematic 토큰 한정)
