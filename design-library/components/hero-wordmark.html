Usage

1. .hero + .hero-* + .btn CSS 블록 통째로 복사
2. eyebrow / wordmark / name / tagline / CTAs 모두 교체

STRUCTURE (위에서 아래로):
.hero-eyebrow    캡스 라벨 (정체성·역할·태그)
.hero-wordmark   시그니처 폰트로 amber 큰 워드마크 (Covered By Your Grace)
.hero-name       본명 또는 부제 (캡스, tracking 4px)
.hero-tagline    한 문장 manifesto, strong은 amber로 강조
.hero-ctas       primary + ghost 2 버튼

WHY THIS WORKS:
- Covered By Your Grace 폰트는 손글씨 느낌 → 따뜻함
- amber 큰 워드마크 = 검은 배경에서 압도적 존재감
- line-height 1.15는 descender(아래 내려가는 글자) 보존 (0.95는 잘림)
- letter-spacing -2px로 자연스러운 손글씨 흐름

WHEN TO USE:
- 허브·랜딩 페이지 첫 화면
- 1인 스튜디오·브랜드 페이지
- 포트폴리오 자기소개 페이지

WHEN NOT TO USE:
- 기능적 페이지 (대시보드, 폼) — 과함
- 기업·기관 페이지 (개인 손글씨 느낌이 안 맞음)
- 작은 카드/모달 내부

CUSTOMIZATION:
- wordmark 텍스트는 짧을수록 좋음 (3-15자)
- 한글도 가능하지만 영문에서 손글씨 폰트가 더 자연스러움
- name 라인은 생략 가능
