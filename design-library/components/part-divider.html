Part 02

이제 직접
손으로 만들어 볼 차례

Usage

1. .ps-divider 블록 전체 CSS 복사
2. 마크업의 part-tag(영문 캡스 라벨) + part-title(한글, strong으로 강조 단어)만 교체

WHEN TO USE:
- 강의·문서를 큰 챕터(Part)로 분리할 때
- 학습자의 인지 리셋이 필요한 자연스러운 휴식 지점
- "여기서부터 새로운 주제가 시작됨"을 강하게 알리는 시각 단절

WHEN NOT TO USE:
- 작은 섹션 구분 (대신 Bilingual Section Header 사용)
- 페이지가 짧을 때(2-3 섹션)는 과함
- Part 라벨 없이 그냥 큰 헤드라인 필요할 때

NOTES:
- min-height: 60vh로 풀스크린에 가까운 임팩트
- part-tag는 amber, letter-spacing 3px (긴장감)
- part-title의 strong은 brand 강조용 (font-weight 700)
