Filled Variant · 강조 + 클릭 유도

USER Primary CTA

Korean Tag · 한글 콘텐츠 (text-transform 해제 권장)

초등 교사 디지털 미디어 실습

Usage

1. .tag-pill CSS 블록 복사 (.amber / .filled 변형은 선택)
2. <span class="tag-pill">TAG</span>로 사용

VARIANTS:
- .tag-pill            기본 (hairline border, 검은 배경)
- .tag-pill.amber      amber border + amber text (강조)
- .tag-pill.filled     amber fill + black text (가장 강한 강조)

KOREAN CONTENT:
- 영문 캡스가 기본이지만, 한글 태그는 style="text-transform: none;" 추가
- 한글 태그는 짧게 (1-3 단어) 권장

WHEN TO USE:
- 카테고리 / 토픽 라벨
- 카드 하단 태그 영역
- 메타 정보 (날짜·길이·대상 등 → 단, dot · 구분자 사용도 가능)

WHEN NOT TO USE:
- 클릭 가능한 버튼 (대신 .btn 사용)
- 본문 강조 (대신 <strong> 사용)
- 4개 초과 연속 배치 시 가독성 ↓ (rows로 나누기)
