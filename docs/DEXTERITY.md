# parcyun dexterity

이 지침은 Dexterity 갤러리와 게시글에 적용한다. 브랜드는 parcyun studio이며 MDBF와 섞지 않는다.

## 화면

- 글 상단 왼쪽에는 ‘← 목록으로 돌아가기’ 텍스트 링크를 제공한다. 향미사는 카페 카테고리(#category-3), 가이드북은 #guidebooks로 복귀한다. 기존 글 끝의 복귀 링크도 유지한다.

- 2026-11-22 배치 보정: 덱스테리티 전체에서 플로팅 ‘쌤 동료에게 공유하기’를 만들지 않는다(다른 페이지에서 클라이언트 이동해도 동일). 글 본문의 별도 공유 기능은 유지한다. 홈 버튼은 공용 플레이어의 왼쪽에 같은 44px 높이로 배치하며 dexterity-home에서만 표시한다. 기존 헤더의 홈 버튼과 임의 margin-right는 제거한다. 공용 플레이어의 기본 상단 여백은 24px, 덱스테리티 모바일의 전용 행은 80px을 유지한다.

- 카드 조회수는 제목 마지막 줄의 우측 끝에 정렬한다. 텍스트 흐름에서 마지막 단어와 조회수 자리는 함께 유지하되, 조회수만 남은 가로 여백만큼 이동한다. ResizeObserver와 폰트 로딩 완료 시 재계산해 숫자 갱신·화면 폭 변경에도 제목 전체 폭과 같은 줄을 유지한다.

- 2026-11-20 독서 동선 보강: 글 테마 토글의 이름은 `밝은 화면`으로 고정하고 light일 때만 aria-pressed=true로 통일한다. 향미사·가이드북 글 끝에서 해당 카테고리로 복귀한다. 카드 상세 설명은 표시하지 않는다. 카드 제목은 서비스명·핵심 정보만 짧게 표시하되 원문 제목·SEO는 보존한다. 제목은 inline으로 카드 폭을 모두 쓰며 조회수는 같은 텍스트 흐름의 마지막 줄 뒤에만 붙인다. 조회수 전용 열·행은 만들지 않는다.

- 좌측 상단에 `parcyun dexterity` 텍스트 로고를 둔다. Covered By Your Grace, 호박색 `#FFB11A`. 갤러리로 연결한다.
- 갤러리는 사진 중심으로 유지한다. 글이 없는 카테고리나 빈 카드는 만들지 않는다.
- 게시글은 브랜드 다크 배경 `#000000`과 흰색 글자, `#333333` 구분선으로 맞춘다. 밝은 화면 토글은 유지한다.
- 원본 글·사진·가격·장소 정보를 임의로 새로 쓰지 않는다. 사람을 비식별 처리한 기존 이미지도 유지한다.
- 향미사 리뷰의 본문은 데스크톱·모바일 15px, 줄 높이 2, 문단 아래 30px를 사용한다. 캡션은 13px와 테마별 보조 회색을 사용한다. 제목·장소 카드에는 해당 본문 규격을 일괄 적용하지 않는다. 본문과 캡션은 사이트의 Montserrat/Pretendard 조합을 유지한다.
- 사용자 요청에 따라 향미사 공간 사진 7장은 정방형으로 표시하고 사진별 object-position으로 천장·주변 여백을 조정한다. 원본 파일과 크게 보기 링크는 보존하며 메뉴판·원두표 2장은 자르지 않는다.
- 사진 클릭 시 native dialog로 원본 전체를 크게 표시한다. 사진·배경 재클릭 또는 Escape로 닫고 원래 사진 링크에 초점을 돌린다. Ctrl/Cmd 클릭의 원본 새 탭 열기는 유지한다.
- ‘입구에서부터 커피 향이 좋았다.’ 같은 짧은 강조문은 본문보다 조금 크게(현재 22px)·600 굵기로 표현한다.
- 모든 HTML 페이지는 DexterityControls 공용 컴포넌트로 우측 하단에 상단 이동 화살표·방문 카운터·브랜드 푸터를 배치한다. 그룹 안의 gap으로 정렬하고 모바일 safe area를 확보한다. 스크롤바만 숨기고 스크롤 동작은 유지한다. 이동은 부드럽게, reduced motion에서는 즉시 처리한다.
- 방문 카운터는 중복 ID 없이 페이지당 하나만 둔다. ‘오늘’과 ‘전체’ 사이 gap을 두고 공용 집계의 하루 중복 방지·한국시간 오전 6시 기준을 유지한다. 홈은 자체 방문과 글 방문 원본 합계, 개별 글은 자체 방문이다.
- 목록 카드 우측 하단에 눈 아이콘과 글의 전체 기간 조회수를 표시한다. 카드 노출이나 클릭으로 조회수를 추가하지 않고 기존 글 페이지 합계를 읽는다. 조회 실패는 숫자 0이 아니라 대시로 둔다. 제목 뒤에는 사진을 살리는 반투명 검정 그라디언트를 적용하고 제목과 수치가 겹치지 않게 공간을 나눈다.
- 홈 상단 우측 원형 홈 버튼은 스튜디오 메인 `/`으로 이동한다. 홈 하단에는 실제 footer 섹션과 도킹 슬롯을 둔다. 플로팅 도구 그룹의 실측 높이만 슬롯에 예약하고, 슬롯이 하단 안전 여백에 도달하면 같은 DOM을 absolute로 전환해 정확히 안착시킨다. 스크롤/리사이즈는 하나의 RAF 컨트롤러로 처리한다.
- 푸터의 바깥 좌우 여백은 `clamp(20px,4vw,48px)`, 바 내부 좌우 여백은 데스크톱 24px·모바일 16px이다. 플로팅/도킹 양쪽에서 같은 gutter를 사용한다. Dexterity에서는 공용 푸터의 `contactLabel="협업 문의"` 변형을 사용하며 다른 서비스의 문구는 바꾸지 않는다.
- 글 끝의 ‘사진 · parcyun / 인물 사진 AI 비식별 편집’ 문구는 노출하지 않는다. 그 자리는 라운드형 장소/지도 영역으로 사용한다.
- Naver Maps 일반 웹페이지는 외부 iframe을 차단한다. 이를 우회하거나 빈 iframe을 배포하지 않는다. 실제 삽입형 지도는 승인된 Maps API 설정으로 구현한다. 설정 전에는 네이버 지도에서 정확한 장소를 여는 카드와 주소를 제공하며, 이를 삽입 지도 완료라고 보고하지 않는다.
- 현재 삽입형 지도는 `public/dexterity-map.js`에서 Dynamic Map + Geocoding을 사용한다. 글 하단이 가까워질 때만 SDK를 불러오고 주소를 매번 조회한다. 결과 좌표·지도 타일을 별도 저장하지 않는다. Client ID는 공개용이며 Client Secret은 프런트엔드·리포에 넣지 않는다.
- Maps 앱 `parcyun-dexterity` 허용 환경은 `https://parcyun.github.io`와 로컬 검수 `http://127.0.0.1:62639`이다. 동적 지도는 일 1,000 / 월 20,000, 주소 검색은 일 1,000 / 월 3,000으로 제한하고 초과 사용은 허용하지 않는다. 콘솔의 ‘대표 계정 미설정’으로 무료 적용 여부는 확인되지 않았으므로 무료라고 단정하지 않는다.
- `Designed by parcyun studio`와 `@parcyun` 푸터를 유지한다.

## 좋아요와 공유

- 지도 미리보기와 장소 링크는 모바일에서 네이버 지도 앱을 즉시 호출한다. iOS는 nmap URL scheme, Android는 intent 및 웹 fallback을 사용한다. PC는 웹 지도. 지도 하단 제공자 표시는 클릭 영역에서 제외한다. 구현: public/dexterity-place.js. 앱 실행으로 페이지가 숨겨지면 iOS fallback을 취소한다. 공식 문서: https://guide.ncloud-docs.com/docs/maps-url-scheme . 실제 기기의 앱 실행은 별도 확인 필요.

- 댓글 입력·목록·GitHub 안내·모달 및 댓글 API 호출은 제거한다. 기존 GitHub issue의 데이터는 삭제하지 않는다.
- 글 하단 중앙에 좋아요와 공유 버튼을 둔다. 좋아요는 글별 localStorage에 저장하며 취소할 수 있다. 전체 독자의 공감 합계로 표시하지 않는다.
- 버튼은 아이콘만 표시하며 접근성 이름은 유지한다. 공유에는 선택 상태를 두지 않고 포인터 호버만 강조한다. 키보드 초점 표시는 유지하며 클릭 즉시 공유/복사를 실행한다.
- 공유는 Web Share API를 우선 사용하고 미지원·실패 시 canonical 주소를 복사한다. 취소하면 복사하지 않는다. 복사 권한이 없으면 선택 가능한 주소를 제공한다.
- Simplification: 좋아요는 현재 브라우저의 선택이다. 전체 합계·기기 간 동기화가 필요해지면 글별 서버 집계와 중복 방지 기능을 추가한다.
- 2026-11-16 검증: build·관련 테스트 4개·JS 구문 검사 통과. Chrome 390/1440px에서 중앙 정렬, 좋아요 저장·새로고침·취소, canonical 링크 복사, 공유 취소 시 복사 없음, 복사 실패 시 주소 선택, 댓글 API 호출 없음 확인. 운영체제 공유창은 브라우저 테스트 대역으로 분기 확인하며 실제 기기 공유 완료는 미검증.

## 원격 작업·배포

- 음악: 홈과 가이드북을 제외한 글은 StudioNavigation·StudioMusicPlayer를 함께 사용해 스튜디오 메인/자료실과 연속 재생한다. 향미사에 적용했다. 가이드북은 제외하며 제외 페이지로 이동할 때 300ms 페이드아웃, 복귀·재개 시 페이드인한다. 상세 운영 기록은 docs/operations/studio-music-20261122.md.

- 2026-11-20: 공통 도구·홈 하단 푸터·카드 조회수 추가. 320px에서 홈/향미사/가이드북 3종의 가로 넘침 없음과 상단 이동을 확인했다. 390/1440px 홈에서 하단 도킹의 오른쪽·아래 경계 오차 0px을 확인했다. 카드 수치는 기존 페이지 합계 읽기 전용이며 새로운 서버 테이블을 만들지 않았다. 실제 모바일 기기 검수는 별도다.

- 정식 리포는 `parcyun/parcyun.github.io`, 공개 경로는 `/dexterity/`와 `/dexterity/hyangmisa/`이다.
- 집의 맥북에서 시작하기 전 `git status`, `git fetch origin`으로 로컬 작업과 원격을 확인하고, 깨끗한 main에서는 `git pull --ff-only origin main`을 사용한다. 미커밋 작업이 있으면 덮어쓰거나 강제 리셋하지 않는다.
- 화면 공통 스타일은 `public/dexterity.css`, 좋아요·공유 동작은 `public/dexterity-actions.js`에 있다.
- `npm run build` 후 `node --test test/dexterity.test.mjs test/dexterity-enhancements.test.mjs`를 실행한다. 모바일·데스크톱에서 로고, 글 상단 수치, 마지막 장소 카드, 좋아요 유지·취소와 공유을 확인한다.
- 푸시 성공과 라이브 반영은 별개다. GitHub Pages Actions 성공 및 공개 URL을 확인하고, 실제로 확인한 범위만 보고한다.
