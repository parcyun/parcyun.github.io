# 게임 계정 연결

## 배포 구성

- Google Cloud / Firebase 프로젝트: `parcyun` (`1093702239224`).
- 로그인: Firebase Authentication / Google 공급자, 공개 이름 `parcyun studio`.
- 허용 도메인: `parcyun.github.io`, `parcyun.firebaseapp.com`, `parcyun.web.app`, `localhost`, `127.0.0.1`.
- 프로필: Firestore `(default)`, 서울 `asia-northeast3`, `profiles/{Firebase UID}`.
- 별명·선택 학교·선택 사진·수정 시각만 프로필 문서에 저장. Google 실명을 기본 별명으로 복사하지 않는다.
- 프로필 사진은 브라우저에서 128×128 WebP로 변환해 저장한다. 외부 업로드 버킷은 사용하지 않는다.
- 개인 기록은 브라우저에 남고, 로그인 후 스펠 드릴 결과 화면 또는 랭킹 하단의 `기록 제출`을 선택하면 서버 최고 기록이 공개 랭킹에 저장된다.
- `spellBoards/{언어}_{난이도}_{모드}/players/{UID}`: 별명·선택 학교 이름·점수·소요 밀리초·실제 플레이 시각·서버 수정 시각만 저장한다. 학교는 새 기록 제출 시에만 공개하며 기존 프로필을 소급 공개하지 않는다. 사진·이메일은 공개하지 않는다.
- 점수 내림차순·소요 시간 오름차순. 50개씩 커서 페이지를 추가하고, 내 순위는 전체 서버 집계로 계산하므로 첫 페이지 밖에서도 정확하다. 완전 동점은 공동 순위다.
- 기존 로컬 기록의 자동 이관은 하지 않는다. 결과가 낮거나 같은 경우 서버 최고 기록과 날짜를 덮어쓰지 않는다.
- Simplification: 점수는 클라이언트 계산값이며 소유자·필드·범위·날짜·최고 기록 갱신만 서버 규칙으로 제한한다. 경쟁 대회·상품 제공을 시작하기 전 서버 발급 라운드와 정답 검증 방식으로 업그레이드해야 한다.
- Firebase 웹 API 키와 앱 ID는 공개 클라이언트 설정이다. 비공개 관리 자격 증명은 사이트에 포함하지 않는다.

## 서버 접근 제한

`firebase/firestore.rules`는 본인 프로필만 조회·생성·수정·삭제할 수 있게 한다. 공개 랭킹은 누구나 조회할 수 있지만 기록 생성·갱신·삭제는 본인만 가능하다. 다른 경로는 허용하지 않는다. 필드 목록·자료형·길이·수정 시각을 서버 규칙에서 검사한다.

규칙 재배포: 인증된 Mac에서 `node scripts/deploy-game-profile-rules.mjs` 실행. 스크립트는 `gcloud`의 현재 로그인 자격으로 `parcyun`에만 배포한다.
랭킹 인덱스: `node scripts/deploy-spell-ranking-index.mjs`. `score DESC / elapsedMs ASC`, collection scope, READY 후 조회 검증.

## UI와 가이드

- `public/game-account.js`: 두 게임의 캐릭터 메뉴·Google 로그인·프로필 수정·약관 링크.
- `public/service-guide.js`: 기존 개발자 인사에 캡처 가이드를 추가. 마지막 페이지도 이전/다음 유지, 다음 비활성화.
- `public/images/guides/`: 실제 게임 화면 캡처. 관련 기능이 바뀌면 캡처를 교체한다.
- 약관: `/terms/`, 개인정보처리방침: `/privacy/`. 신규 개인정보 항목을 저장하기 전에 실제 처리 방식과 함께 갱신한다.

## 확인 기록 (2026-10-29)

- Google 공급자 활성화와 사이트 도메인 허용 완료.
- Google 인증 플랫폼 공개 대상이 외부·프로덕션 상태임을 콘솔에서 확인.
- Chrome의 실제 Google 로그인 성공, 무작위 별명·128px 변환 사진 저장 및 새로고침 후 프로필 재조회 확인.
- 로그인 없는 프로필 API 조회는 HTTP 403.
- 한글/영어 홈의 제목·컨트롤·전체 높이 동일함을 브라우저에서 측정.
- 390px 화면에서도 한글/영어 홈 높이와 컨트롤 높이가 같고 가로 넘침이 없음을 확인. 스튜디오 메뉴의 공유·커피는 데스크톱 좌우, 모바일 공유 위·커피 아래로 배치.
- 인앱 브라우저의 인증 팝업은 별도 창 추적이 제한되어 Chrome에서 인증을 검증했다. 기본 게임 이용은 로그인에 의존하지 않는다.
- 실제 1문항 정답 → 게임 종료 → 서버 최고 기록 제출 → 전체 랭킹과 내 순위·플레이 시각 재조회 확인. 테스트 별명 `숲속수달`, 초급·연습 130점. 임의로 만든 순위표 데이터는 사용하지 않았다.
- 홈 미리보기: `scripts/build-gallery-previews.mjs`가 실제 캡처 원본에서 18개 2초 무음 루프 영상을 재생성한다. 영상은 contain 배치, 지연 로드, 호버/키보드 포커스 재생, 이탈/탭 비활성화 시 정지한다. PDF 1페이지 자료는 같은 페이지를 유지한다.

## 랭킹 학교명 표시 (2026-10-29)

- 기존 스타일과 별명을 유지하고 플레이어 아래에 제출 시의 학교 이름을 표시한다. 미입력자는 계정별로 고정된 무작위풍 모험 별명을 표시한다. Dexter 별명은 개발자로 표시하며 권한에는 영향이 없다.
- 기존 비공개 프로필을 읽거나 소급 공개하지 않는다. 새 기록 제출 안내와 개인정보처리방침·약관에 학교명 공개를 명시한다. 기존 최고 기록을 갱신하지 않으면 학교명도 갱신하지 않는다.
- 관련 테스트 7개 및 Astro 빌드 통과. 실제 로그인 후 학교명 포함 제출과 모바일 모달은 미검증이며 다음 확인 대상이다.

- 예약 닉네임: DEXTER·parcyun을 대소문자 무관하게 포함한 문자열은 프로필 저장·랭킹 제출 양쪽에서 차단한다. Firestore 규칙도 동일하게 적용한다. 기존 데이터는 삭제하거나 개명하지 않으며 해당 사용자는 프로필에서 별명을 바꿔야 다음 제출이 가능하다.
