# 방문 집계 — 2026-11-16

- 저장 원본은 Supabase `page_visits`의 페이지·수업일별 방문 기록이다. 같은 브라우저는 페이지별로 한국시간 오전 6시 기준 하루 한 번 집계한다. 사람을 식별한 순수 방문자 수가 아니므로 페이지 합계에는 같은 사람이 서로 다른 페이지를 방문한 기록이 각각 포함된다.
- 공용 `public/visitor-counter.js`의 `parentScopes`가 표시 범위를 관리한다. 최초 방문·재방문 모두 동일한 읽기 RPC로 표시한다.
- 홈: 공개 페이지의 원본 기록 합계. 아틀라스: 자체 페이지와 Spell Drill·GeoWeb·satury·입체 부피 도구. 아카데미카: 자체 페이지와 내부 강의 자료. Works: 자체 페이지와 내부 포트폴리오.
- 개별 서비스: 자체 페이지 기록만 표시한다. 카드 클릭 수·외부 서비스 이용 수는 사이트 방문 합계에 섞지 않는다.
- 상위 페이지 합계는 저장된 하위 원본을 한 번씩만 더한다. 상위 합계를 다른 상위 합계에 다시 더하지 않는다.
- 기존 원본·별칭·옛 주소 기록은 수정하거나 삭제하지 않았다. 과거 Spell Drill 이관 기록은 별도 보관분을 재합산하지 않아 이중 집계를 피한다. 개발·진단 경로는 홈 합계에서 제외한다.
- 상위 집계 읽기가 실패하면 잘못된 자체 방문수로 대체하지 않는다. 다음 방문 때 다시 읽는다.
- 서비스 추가 시 집계 범위도 업데이트한다. 카탈로그의 `visitPath`는 회귀 테스트가 홈·아틀라스 포함 여부를 검사한다.
- 모든 카운터 로딩 주소를 `?v=20261116-hierarchy-1`로 갱신해 이전 스크립트 캐시를 피한다.
