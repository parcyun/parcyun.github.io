# 공용 미니 음악 플레이어

2026-11-22. 범위: `/`, `/dexterity/`, `/atlas-gears/`, `/academica/`의 우측 상단. 기존 사진·로고·홈 버튼·공용 메뉴·푸터는 보존한다. Dexterity 모바일에서는 로고/홈 버튼 아래 행에 플레이어를 두어 겹침을 피한다.

최종 선택: 사용자는 자체 미니 플레이어 UI를 우선하고, Suno 임베드로 같은 제어가 불가능하면 기존 MP3 방식으로 진행하도록 지시했다. 공식 임베드를 숨기거나 비공개 통신 규약을 역이용하지 않고 현재 로컬 음원 방식으로 배포한다. 이 재생은 YouTube/Suno 재생수 집계를 보장하거나 제공하지 않는다.

UI는 44px 터치 영역의 재생/일시정지 아이콘과 12px 곡명뿐이다. 키보드 초점·접근성 이름·실제 재생 상태를 유지한다. 두 곡을 순서대로 무한 반복한다. 첫 방문은 자동재생을 시도하되 브라우저가 거부하면 재생 버튼 안내를 제공하며 정책을 우회하지 않는다. 명시적 일시정지는 sessionStorage에 보존한다.

연속 재생: Astro ClientRouter와 transition:persist로 네 메인 페이지 및 가이드북을 제외한 Dexterity 글에서 실제 오디오 요소를 유지한다. 현재 비가이드 글은 향미사다. 새 글도 StudioNavigation과 StudioMusicPlayer를 포함해야 한다. 기존 전역 스크립트는 psPageLifecycle에서 새 body에 다시 연결하고 이전 이벤트·관찰자를 정리한다. 계정·공용 메뉴 싱글턴은 컨트롤러와 함께 유지한다. 가이드북에는 라우터·플레이어를 넣지 않는다.

일시정지·음악 제외 링크 이동은 300ms 음량 페이드아웃 후 정지하며, 재개·돌아오기는 페이드인한다. 연속 재생 대상끼리는 페이드나 음원 재요청이 없다. 사용자가 주소창에서 직접 이동하거나 탭을 닫는 동작은 비동기 페이드를 보장할 수 없다. 일부 모바일 브라우저의 음량 제어·자동재생 제한은 실제 기기 확인이 필요하다. 아이콘은 다음 동작을 표시한다: 정지 중 ▶ 재생, 재생 중 Ⅱ 일시정지. 2026-11-22 역전 표시 오류 수정: 실제 브라우저에서 초기 정지·재생·재정지와 아이콘 일치 확인, 관련 테스트 7개 및 빌드 통과.

2026-11-22 추가 검수: 실제 Chrome에서 메인→아카데미카→아틀라스→메인→덱스테리티→향미사 및 뒤로/앞으로 이동 동안 동일 audio 객체, pause/emptied/loadstart 이벤트 0건 확인. 명시적 정지 유지, 0→1/1→0 페이드, 가이드북 제외와 돌아오기 재개 확인. 390px 향미사 헤더와 플레이어 비중첩 확인. 물리 모바일 기기는 미검증.

추가 관련 테스트 34개 통과, build 및 diff 공백 검사 통과. 전체 테스트는 368개 중 363개 통과, 5개 실패: contact-api의 미설치 의존성, ResourceHoverPreview의 이전 OG 경로 기대, Spell Drill 점수 문구 기대, 갤러리 영상 개수 18 기대(현재 19), 기존 홈 링크의 편집 ID 누락. 해당 대상 구현·데이터는 이번 음악 작업에서 변경하지 않았으며 전체 테스트 통과로 보고하지 않는다. 실제 MP3 끝부분 이동을 통한 1→2→1 반복도 추가 확인했다.

음원은 연결된 Suno 라이브러리에서 소유 계정의 공개·완료된 정식 버전을 확인하고 MP3 다운로드했다. 다른 곡인 로컬 reference.mp3는 사용하지 않았다.

- [I love this Christmas city](https://suno.com/song/c8cb2a6d-95a1-4165-afe4-b555c79f45e8): 179.88초, 4,571,348바이트.
- [Slow Side of Sunday](https://suno.com/song/129f7538-5d2e-4f7f-904c-7485e11829be): 승인된 B 버전, 266.96초, 6,616,145바이트. 다운로드 크레딧 1개 사용은 사용자 승인 후 수행했다.

구현: `src/components/StudioMusicPlayer.astro`, `public/studio-music.js`, `public/audio/studio/`. 서명된 임시 다운로드 URL은 리포에 넣지 않는다. 로컬 음원 경로를 사용해 외부 CDN 만료·CORS 의존성을 없앴다. 음원 교체 시 파일명 버전을 올려 브라우저 캐시와 혼동하지 않도록 한다.

검증 명령: `npm run build`, `node --test test/studio-music.test.mjs`. 실물 모바일·청취 음질은 브라우저 뷰포트/재생 상태 검증과 구분해서 보고한다.

로컬 검증: 관련 테스트 총 25개 통과. 실제 Chrome에서 첫 진입 음원 요청 0건, 재생·일시정지, 실제 끝부분 이동을 통한 1→2→1 전환, 키보드 Space 일시정지, 페이지 이동 후 재생 위치 복원을 확인했다. 문서 이동 후 자동재생이 브라우저에 의해 거부되는 경로도 관찰했으며 버튼을 눌러 30초 위치에서 정상 재개했다. 320/390/768/1440px 네 루트에서 배치와 기존 버튼 겹침을 확인했다. Academica의 기존 모바일 푸터 넘침이 layout viewport를 넓히는 경우에도 플레이어는 100vw 기준으로 고정해 화면 안쪽 20px에 남도록 했다. 기존 푸터 자체는 이번 범위에서 수정하지 않았다.
