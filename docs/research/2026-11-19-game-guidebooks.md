# 세 서비스 가이드북

- 기존 Dexterity 사진 갤러리와 다크·밝은 화면을 유지하며 `가이드북`에 지오웹·스펠드릴·사투리 글을 추가했다.
- 말투는 사용자가 지정한 인디스쿨 지오웹 소개 글의 짧은 설명·수업 질문·실제 사용 순서를 참고했다. 기존 장소 글과 사진은 수정하지 않았다.
- 본문은 `src/data/gameGuides.ts`와 `GameGuideArticle.astro`에서 한 번 작성한다. 공개 글과 각 서비스 푸터의 팝업은 같은 렌더링 결과를 사용한다.
- 게임 링크는 썸네일 이미지가 있는 라운드 박스이며 새 탭에서 열린다. 가이드 팝업은 native dialog로 하단에서 올라오며 자체 본문 스크롤, Escape·닫기·배경 클릭, 원래 버튼 초점 복원을 제공한다. 이동 줄이기에서는 애니메이션을 생략한다.
- 모바일 지오웹의 기존 푸터 버튼 숨김 정책에 가이드북 예외를 적용해 실제 하단에서도 열 수 있게 했다. 390px에서 세 팝업의 가로 넘침 없음, 사투리 CSS의 article grid 충돌 수정, 데스크톱의 세 연결·밝은 화면·닫기 동작을 실제 UI에서 확인했다.
- 사투리는 게임이 아닌 사전 검색 도구이므로 팀전·프로필 기능을 있다고 소개하지 않는다. 표준국어대사전·우리말샘 원자료와 지역·시기별 차이의 한계를 안내한다.
- 지오웹 화면은 이번 요청에서 촬영한 공개 화면과 촬영용 별명을 사용한 대항전 화면을 재사용했다. 스펠드릴은 기존 자체 사용 안내 이미지를 재사용했다. 사투리 옥수수 검색 결과는 새로 촬영했다.
- 자동 검사 28개(가이드·기존 Dexterity·공용 푸터·방문 집계)와 전체 빌드 통과. 방문 집계 원본·서버·권한은 변경하지 않았으며 새 글은 기존 카운터를 사용한다.
- 라이브 GitHub Pages 완료와 공개 URL 확인은 배포 후 별도 수행한다.
