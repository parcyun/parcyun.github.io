# 세 서비스 가이드북

- 기존 Dexterity 사진 갤러리와 다크·밝은 화면을 유지하며 `가이드북`에 지오웹·스펠드릴·사투리 글을 추가했다.
- 말투는 사용자가 지정한 인디스쿨 지오웹 소개 글의 짧은 설명·수업 질문·실제 사용 순서를 참고했다. 기존 장소 글과 사진은 수정하지 않았다.
- 본문은 `src/data/gameGuides.ts`와 `GameGuideArticle.astro`에서 한 번 작성한다. 공개 글과 각 서비스 푸터의 팝업은 같은 렌더링 결과를 사용한다.
- 게임 링크는 썸네일 이미지가 있는 라운드 박스이며 새 탭에서 열린다. 가이드 팝업은 native dialog로 하단에서 올라오며 자체 본문 스크롤, Escape·닫기·배경 클릭, 원래 버튼 초점 복원을 제공한다. 이동 줄이기에서는 애니메이션을 생략한다.
- 모바일 지오웹의 기존 푸터 버튼 숨김 정책에 가이드북 예외를 적용해 실제 하단에서도 열 수 있게 했다. 390px에서 세 팝업의 가로 넘침 없음, 사투리 CSS의 article grid 충돌 수정, 데스크톱의 세 연결·밝은 화면·닫기 동작을 실제 UI에서 확인했다.
- 사투리는 게임이 아닌 사전 검색 도구이므로 팀전·프로필 기능을 있다고 소개하지 않는다. 표준국어대사전·우리말샘 원자료와 지역·시기별 차이의 한계를 안내한다.
- 지오웹 화면은 이번 요청에서 촬영한 공개 화면과 촬영용 별명을 사용한 대항전 화면을 재사용했다. 스펠드릴은 기존 자체 사용 안내 이미지를 재사용했다. 사투리 옥수수 검색 결과는 새로 촬영했다.
- 자동 검사 28개(가이드·기존 Dexterity·공용 푸터·방문 집계)와 전체 빌드 통과. 방문 집계 원본·서버·권한은 변경하지 않았으며 새 글은 기존 카운터를 사용한다.
- 라이브 GitHub Pages 완료와 공개 URL 확인은 배포 후 별도 수행한다.

## 2026-11-20 상세 화면 보강
- 실제 공개 화면에서 촬영한 생성/참여/사전 결과·상세와 앞선 실제 경기 검수 화면을 포함한 WebP 9장을 추가했다. 기존 사진은 유지한다.
- 일반 수도 게임에 없는 위치 맞추기 설명, 모바일에서 맞지 않는 프로필 아이콘 위치 설명, 두 게임에 공통으로 존재하지 않는 계정 재확인 버튼 지시를 삭제·수정했다. 사투리 검색 및 상세 뜻풀이는 실제 동작을 확인하고 사진을 보강했다.
- 독립 가이드 페이지 마지막 섹션에 구분선과 현재 글을 제외한 두 가이드의 수평 스냅 캐러셀을 추가했다. 스와이프/스크롤·키보드·이전/다음 버튼과 이동 줄이기를 지원한다.
- 빌드와 기존 가이드 검사 4개 통과. 로컬 빌드를 실제 Chrome에서 세 글 PC/390px 모바일로 확인하여 화살표 왕복, 다른 두 글 링크, 가로 넘침 없음을 확인했다. 추가 화면·내용 검증은 촬영 결과와 현재 소스에 근거한다.
- 이번 변경은 아직 라이브에 배포하지 않았다.
- 후속 보강: 평면·Focus Lens·지구본, 대륙 선택, 지형 범례 5종, 실제 크기 비교 도형 이동, 낮과 밤, 위성 사진, 게임 목록, 난이도 선택을 실제 공개 화면에서 새로 촬영해 WebP 10장과 각 단계 설명을 추가했다. 기존 기후·국가 정보·인구 안내를 유지했다. 빌드와 가이드 검사 4개 통과, 로컬 PC·390px 가로 넘침·캐러셀 회귀 확인. 라이브 미반영.
- 순서 후속: 지오웹은 지도·기후·인구 등 기본 도구 전체 → 게임모드·난이도 → 대항전 → 브라우저 프로필 → 공개 랭킹 순으로 정리했다. 스펠드릴도 공개 랭킹을 프로필 직후로 이동했다. 사투리는 검색 → 뜻풀이 → 지역·출처 순서를 유지하고 공통 카드·캐러셀을 공유한다. 두 게임 랭킹 실화면 WebP 2장을 추가했다. 서비스 카드의 호버/키보드 초점에 테두리·그림자와 작은 이동을 적용하고 reduced-motion에서는 움직임을 생략한다. 빌드·가이드 검사 5개 통과, PC/모바일 세 글 호버·캐러셀 회귀 점검. 라이브 미반영.
- 이미지 검수 후속: 전체 32개 고유 사진의 내용과 PC/390px 본문 배치를 확인했다. 전환 중 빈 지오웹 방 만들기 사진과 로딩 중인 사투리 검색 사진을 다시 촬영해 교체했다. 스펠드릴 기본 시작·플레이 사진은 현재 라이브 UI로 다시 촬영했다. 이미지 원본 확대 안내를 추가하고 테두리를 포함한 너비가 본문을 넘지 않게 조정했다. 이미지 decode·원본 종횡비·화면 폭 검사와 가이드 테스트 5개·빌드 통과. 라이브 미반영.
