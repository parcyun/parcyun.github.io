# GeoWeb 지역별 격자 인구밀도 히트맵 (2026-11-19)

## 국가 평균 방식의 교정

이번 자료는 국가에 단색을 입히는 이전 국가 평균 자료를 대신한다. 국경·해안선·실제 위치는 그대로 두고, 같은 국가 안에서도 도시·농촌·산지에 따라 색이 달라지는 **실제 격자 인구밀도 자료**다. 인구 카토그램으로 늘린 면적이나 임의로 찍은 도시 점을 사용하지 않았다.

## 검증된 원 자료

- [WorldPop 공식 ArcGIS item](https://www.arcgis.com/home/item.html?id=38b7672a1977426caa6cf4c62e37b777), 소유자 `WorldPop_Project`.
- [WorldPop Population Density 1km ImageServer](https://worldpop.arcgis.com/arcgis/rest/services/WorldPop_Population_Density_1km/ImageServer): 공개·인증 없는 서비스. 원 자료는 30 arc-second(적도 부근 약 1km), WGS84, 연도 2000–2020, 단위 명/km²다.
- [원 데이터 DOI 10.5258/SOTON/WP00674](https://doi.org/10.5258/SOTON/WP00674). WorldPop·CIESIN이 제작한 top-down unconstrained Random Forest 기반 분포 **추정치**다. 픽셀 인구를 픽셀의 실제 표면적으로 나눠 밀도로 변환한다. 2020년 각 격자를 직접 실측한 자료라고 표현하지 않는다.
- 공식 item은 **CC BY 4.0**으로 상업적 이용·변형을 포함한 재사용을 허용하며 출처 표기가 필요하다고 명시한다. 출처는 저장 메타데이터와 별도 attribution 파일에 보존했다. 지도에 새 설명 문단을 띄울 필요는 없다.

## 추출·색상 처리

서비스 `exportImage`에 bbox `-180,-90,180,90`, bboxSR/imageSR `4326`, size `4096,2048`, time `1577836800000`(2020-01-01 UTC), format `tiff`, pixelType `F32`, renderingRule `None`을 지정했다. 원본 밀도 수치의 **TIFF 33,493,808바이트**를 받아 색상을 직접 분류했다. 수치 추출의 실제 URL·해시·서비스 응답은 결과 메타데이터와 외부 검증 자료에 보존한다.

출력 텍스처는 전 지구 등장방형 4096×2048, 첫 행이 북쪽(90°N), 첫 열이 서쪽(180°W)이다. 표시는 원 1km 자료를 bilinear로 재표본화한 것으로, 출력 한 픽셀의 해상도가 1km라는 뜻은 아니다. 확대 시 1km급의 모든 세부를 재현하지는 못한다.

5개 표시 구간은 GeoWeb의 디자인 선택이다. `[0,1)`, `[1,10)`, `[10,100)`, `[100,1000)`, `[1000,∞)`명/km²이며, 각각 RGBA `(255,245,240,12)`, `(253,208,193,45)`, `(252,160,130,95)`, `(239,90,67,165)`, `(183,25,43,230)`을 쓴다. 저밀도는 거의 투명하고 고밀도는 짙은 빨강이다. 공식 WorldPop 분류라고 주장하지 않는다.

**NoData 주의:** F32 export에는 바다·자료 없음에 양의 `3.4e38` sentinel이 들어 있었고 TIFF NoData mask로 자동 인식되지 않았다. 따라서 음수·비정상·`>=1e30` 값은 전부 투명 처리했다. 이 검사를 빼면 바다가 최고밀도 빨강으로 바뀌는 오류가 난다.

## 검증

서울 위치 격자 약 9,541명/km², 델리 약 2,243, 도쿄 약 26,841, 뉴욕 약 9,056이며 몽골 농촌 표본은 약 0.75, 사하라 표본은 약 0.20이다. 이들은 해당 좌표의 재표본화 격자값이며 도시 전체 평균이 아니다. 같은 한국 내 서울과 산지 표본의 색·밀도 차이도 확인했다.

PNG·metadata는 `public/lab-data/geoweb-population-density-regions.png` 및 같은 이름의 `.json`이다. 메타데이터에 유효 픽셀 수, 분류별 픽셀 수, 수치 범위, 표본 수치, source/texture SHA256을 기록했다. `test/geoweb-regional-density-data.test.mjs`는 크기·좌표 방향·바다 투명도·도시/농촌 차이·메타데이터 해시를 검사한다.

원 서비스는 2026년 8월 mature support, 2027년 12월 retirement 예정이라는 안내가 있다. 이 구현은 추출한 정적 PNG를 로컬에서 제공하므로 실행 중 원 서비스에 의존하지 않는다. SEDAC 구 WMS 주소는 이번 검증에서 timeout이 나서 채택하지 않았다.

## 생성기와 폐기한 접근

`python scripts/build-population-density-regions.py /path/density-2020-float.tif`로 같은 색 분류를 재현한다. 개발 도구에만 numpy·rasterio·Pillow가 필요하며 앱 의존성은 추가하지 않는다. TIFF의 크기·좌표계·extent를 검사해 다른 투영 자료를 잘못 끼우는 것을 막는다. 원 수치 TIFF와 export 응답은 외부 검증 자료 디렉터리에 보존했다.

사용자 정정에 따라 국가 평균 밀도를 그리던 이전 generator·JSON·test·attribution은 앱 트리에서 제거하고 외부 research artifacts의 `superseded-country-average`에 원본을 보존했다. 국가 평균 값이 격자 히트맵으로 혼동되어 다시 쓰이지 않도록 한 조치다.

## 로컬 UI 검수 결과

2026-11-19 로컬 `http://127.0.0.1:47613/world-map/`에서 평면·Focus Lens·지구본에 동일한 지역 격자 질감이 나타나고 국가 경계가 유지됨을 화면으로 확인했다. 밀도 지역 경계선은 추가하지 않았다. 인구 밀도와 인구 비례 모핑은 서로 독립된 보기로 전환하며, 밀도를 켜면 원래 지리 좌표로 복귀한다. 도구 상자는 밀도/인구 전환 전후 너비 316.5546875px, 높이 530px이고 토글 좌표도 동일했다(1423×718 화면). 설명 문단·외부 링크를 새로 노출하지 않는다.

단위·범례 일치 및 기존 인구 모핑 회귀 10개, 실제 지역 자료 검증 4개 통과. Astro 전체 21페이지 빌드 통과. 라이브 배포는 요청 범위에 없으므로 수행하지 않았으며 로컬 서버를 유지한다. 검수 화면은 외부 Artifacts의 `geoweb-population-verification-20261119/regional-density-*.png`에 보관했다.

### 후속 요청 반영

인구 비례 지도와 밀도를 함께 켤 수 있도록 변경했다. 밀도는 원래 격자 좌표로 샘플링한 뒤 같은 국가의 모핑된 표면에 표시한다. `국가 선택`은 인구 토글 아래 행에 위치하며 숨김 상태에서도 자리를 예약한다. 실제 UI에서 두 토글 동시 활성화와 모핑 위 밀도 표시, 아래 행 배치를 검증했다. 앞서 기록한 상호 배타 전환 정책은 이 요청으로 대체되었다.

### 라이브 반영 전 최종 검수

평면·Focus Lens·지구본 각각 인구 비례 단독, 밀도 단독, 동시 표시의 9개 조합을 실제 로컬 화면에서 확인했다. 격자 간격 입력은 격자 토글 오른쪽으로 이동하고 접근성 이름 `간격`을 유지한다. 관련 검사 20개와 21페이지 빌드 통과. 기후 검사에서 삭제 요청된 설명·외부 링크 기대값과 밀도 우선 색상 기대값을 새 동작에 맞췄다. 배포 결과는 GitHub Pages workflow와 공개 URL에서 별도 확인한다.

### 국가 선택 버튼 통합

후속 요청으로 아래쪽 국가 선택 버튼을 제거하고 위쪽 공용 토글 하나로 통합했다. 인구 보기를 켜면 위 토글을 그대로 사용할 수 있고 실제 크기 비교는 비활성화된다. 국가 선택을 켜면 원래 지도 위 선택 국가 인구 비례 오버레이를 사용하며, 끄면 전체 인구 모핑 및 현재 국가의 대륙 정보로 전환한다. 프랑스 선택→토글 끄기→유럽 정보 전환을 실제 UI로 확인했다. 관련 검사 20개·전체 빌드 재통과.
