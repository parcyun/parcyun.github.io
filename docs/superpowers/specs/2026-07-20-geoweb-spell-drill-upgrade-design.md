# GeoWeb 국가 탐색·Spell Drill 점수 시스템 개선 설계

## 목표

GeoWeb을 195개국을 검색하고 핵심 국가 정보를 탐색할 수 있는 초등 세계지리 도구로 확장한다. Spell Drill은 설명하지 않아도 플레이 중 규칙을 발견할 수 있는 콤보 보상·패스 페널티·점수 이펙트를 갖춘다.

## 범위

### GeoWeb

- UN 회원국 193개국과 옵서버국 바티칸·팔레스타인을 합친 195개국을 제공한다.
- 각 국가에 ISO alpha-2/alpha-3 코드, 한글·영문 국가명, 한글·영문 수도명, 대략적 인구와 기준 연도, 중심 좌표, 대륙, 정치 체제, 경제 체제, 로컬 국기 경로를 둔다.
- 정치 체제는 `민주공화국`, `입헌군주국`, `전제군주국`, `일당제`, `과도정부·특수`로 분류한다.
- 경제 체제는 `시장경제`, `혼합경제`, `사회주의 시장경제`, `계획경제`로 분류한다.
- 국가·수도 한글명은 정적 데이터에서 직접 관리하여 한국어 모드에서 영어가 섞이지 않게 한다.
- 국기는 신뢰 가능한 공개 원본을 받아 WebP로 변환하고 저장소에서 정적으로 제공한다.
- 기존 대륙·대양 패널 아래에 국가 검색창을 둔다.
- 검색 중에는 짧은 로딩 애니메이션을 표시한다. 검색 결과를 선택하면 패널이 아래로 확장되며 국가 정보가 나타나고, 지도는 해당 국가를 중앙에 두고 부드럽게 확대한다.
- 정치·경제 체제 텍스트는 인터랙티브 요소다. 누르면 해당 용어 설명이 버튼 바로 위의 팝오버로 나타난다.
- 검색 결과, 용어 팝오버, 기존 도구·범례 상자의 접힘과 펼침은 같은 easing과 높이·투명도 전환을 사용한다.
- 키보드 조작과 Escape 닫기, `prefers-reduced-motion`을 지원한다.

### GeoWeb 업데이트 이야기

- 새 업데이트 버전으로 처음 접속했을 때만 업데이트 안내 모달을 띄운다.
- 문구는 개발자가 교실의 사용자에게 직접 건네는 친근한 이야기 형식으로 쓴다.
- 모달에는 이번 업데이트의 핵심인 195개국 검색, 수도·인구·체제·국기 정보, 부드러운 탐색을 간결하게 소개한다.
- 닫으면 업데이트 버전을 브라우저 저장소에 기록하여 같은 버전에서는 다시 자동 표시하지 않는다.
- 저장소 접근이 불가능하면 페이지 기능에는 영향을 주지 않고 세션 중 한 번만 표시한다.

### Spell Drill

- 콤보 배율을 다음과 같이 적용한다.
  - 0~2 콤보: 1배
  - 3~5 콤보: 1.5배
  - 6~8 콤보: 2배
  - 9~11 콤보: 3배
  - 12~14 콤보: 4배
  - 15 콤보 이상: 5배 고정
- 패스 감점은 한 게임 안에서 누적 횟수에 따라 `10 × 2^(패스 횟수-1)`점으로 증가한다.
- 패스 감점 규칙과 라이트닝 발동 조건은 UI에 설명하지 않는다.
- 보너스와 감점 발생 시 점수 변화량을 보여주는 이펙트를 낸다. 절댓값이 클수록 글자 크기, 글로우, 입자 수와 이동 거리가 증가한다.
- 보너스는 앰버·골드 계열, 감점은 적색 계열로 구분한다.
- 점수는 0 미만으로 내려가지 않는다.
- 패스 누적 횟수는 새 게임 시작 시 초기화한다.

## 데이터 구조

국가 데이터는 애플리케이션과 분리된 정적 모듈로 둔다. 지도 경계의 ISO 코드와 국가 데이터의 ISO alpha-3 코드를 기본 연결 키로 사용하며, 기존 경계 데이터에 코드가 없거나 다른 경우에만 명시적 별칭 표를 둔다.

국기 파일명은 ISO alpha-2 소문자 코드로 통일한다. 예: `kr.webp`, `us.webp`.

## 인터랙션과 애니메이션

GeoWeb 패널 전환은 `cubic-bezier(0.16, 1, 0.3, 1)`을 기본 easing으로 사용한다. 레이아웃은 측정된 높이를 기준으로 전환하여 내용이 잘리지 않게 하고, 모션 감소 환경에서는 즉시 상태를 전환한다. 지도 이동은 현재 투영법에 맞춰 중심 좌표와 줌을 보간한다.

Spell Drill 점수 이펙트는 DOM 오버레이와 CSS 애니메이션으로 구현한다. 게임 계산과 표현을 분리하여 점수 규칙을 순수 함수로 검증한다.

## 오류 처리

- 국기 파일을 찾지 못하면 ISO 코드가 들어간 중립 플레이스홀더를 표시한다.
- 검색 결과가 없으면 패널 내부에 명확한 빈 상태를 표시한다.
- 지도 데이터와 국가 정보가 연결되지 않은 항목은 빌드 전 검증 테스트에서 실패시킨다.
- 업데이트 모달의 저장 상태 오류는 무시하고 핵심 기능을 계속 제공한다.

## 검증

- 정적 국가 데이터가 정확히 195개이며 ISO 코드, 한글·영문 이름, 수도, 인구, 정치·경제 체제, 중심 좌표, 국기 경로를 모두 갖는지 검사한다.
- 모든 국기 WebP 파일의 존재와 포맷을 검사한다.
- 한국어 모드에서 195개 국가·수도에 한글 값이 존재하는지 검사한다.
- 검색 결과 선택 시 국가 선택과 지도 중심 이동 API가 함께 호출되는지 검사한다.
- 용어 팝오버와 패널 접힘에 접근성 상태가 반영되는지 검사한다.
- 콤보 경계값 0, 3, 6, 9, 12, 15, 30과 패스 1~6회의 점수를 단위 테스트한다.
- 새 게임에서 패스 횟수가 초기화되고 점수가 0 아래로 내려가지 않는지 검사한다.
- 모션 감소 설정에서 장식 애니메이션이 제거되는지 검사한다.
- 전체 Node 테스트와 Astro 빌드를 통과시키고, 로컬 브라우저에서 GeoWeb 검색·지도 이동·팝오버·업데이트 안내와 Spell Drill 점수 이펙트를 확인한다.
