# GeoWeb · Spell Drill 온보딩, 검색, 점수 피드백 개선 설계

## 목표

GeoWeb과 Spell Drill의 첫 접속 경험을 개발자의 친근한 안내로 통일하고, GeoWeb 국가 검색을 실제 사용자의 표현과 오타까지 다루도록 개선한다. Spell Drill에서는 오답 반복에 따른 누적 감점과 더 강한 점수 피드백을 제공하되 규칙을 직접 설명하지 않는다.

## 접근 방식

### 검토한 선택지

1. **정확 검색만 유지하고 별칭 목록 추가**
   - 오탐은 적지만 오타 검색을 해결하지 못한다.
2. **모든 검색에 문자열 유사도를 적용**
   - 구현은 단순하지만 짧은 검색어에서 무관한 결과가 많아진다.
3. **정확 일치 → 통용 별칭 → 제한된 유사 검색의 혼합 방식**
   - 정확한 결과를 보호하면서 실제 표현과 오타를 함께 지원한다.

선택: 3번. 통용 별칭은 정적 데이터로 관리하고 일반 결과로 취급한다. 문자열 유사도로만 찾은 결과에는 `유사 결과` 태그를 표시한다.

## GeoWeb

### 랜딩 모달

- 기존 개발자 이야기 어조와 버전별 1회 노출 정책을 유지한다.
- 검색 중심 문장을 제거하고 다음 네 가지 사용법을 한 줄씩 안내한다.
  - 상단 버튼으로 평면·Focus Lens·지구본 뷰 전환
  - 대륙·대양 선택으로 지도 영역 탐색
  - 낮과 밤 기능으로 태양빛에 따른 명암 관찰
  - 위도·경도 격자로 지구상의 위치 이해
- 주 버튼 문구는 `시작하기`로 변경한다.
- 버튼 아래에 작은 회색 `업데이트 내역 보기` 토글을 둔다.
- 토글을 누르면 모달 안에서 버전별 변경 내역이 아래로 부드럽게 펼쳐진다.

### 패널 분리

- 기존 대륙·대양 패널에서 국가 검색 UI를 제거한다.
- 오른쪽 스택에 `대륙·대양 선택`, `국가 검색`, `국가 정보 카드`를 각각 독립된 상자로 배치한다.
- 대륙·대양 패널을 접어도 검색 패널은 유지한다.

### 국가 검색

- 결과 우선순위:
  1. 국가명·공식명·수도·ISO 코드의 정확/부분 일치
  2. 정적 통용 별칭 일치
  3. 편집거리 기반 유사 결과
- 대표 별칭에는 북한/남한, 미국/영국/러시아/베트남 등 한국어 통용명과 일반 영어 약칭을 포함한다.
- 유사 검색은 정규화 후 최소 길이와 거리 비율 제한을 적용해 억지 결과를 차단한다.
- 반환 결과는 `{ country, matchType }` 구조로 검색 근거를 UI에 전달한다.
- `matchType === "fuzzy"`인 결과에만 `유사 결과` 태그를 표시한다.

### 체제 팝업 수명

- 국가가 변경되거나 선택이 해제되거나 카드가 닫히면 `systemPopover`를 `null`로 초기화한다.
- 정치·경제 설명 중 하나만 열릴 수 있다.

## Spell Drill

### 랜딩 모달

- 첫 접속 시 개발자가 사용자에게 말을 거는 어조로 게임 사용법을 안내한다.
- 기존 시작 화면보다 먼저 표시하며 `시작하기`를 누르면 닫힌다.
- 주 버튼 아래에 GeoWeb과 같은 `업데이트 내역 보기` 아코디언을 둔다.
- 버전별 노출 여부는 별도 localStorage 키로 관리한다.

### 누적 오답 감점

- 게임 시작 때 `wrongCount = 0`으로 초기화한다.
- 오답마다 1 증가하며 감점은 `wrongCount × 10`이다.
- 예: 1회 10점, 2회 20점, 3회 30점, 4회 40점.
- 오답을 맞힌 뒤에도 게임이 끝날 때까지 오답 횟수는 유지된다.
- 패스 누적 감점 규칙과는 독립적이다.

### 점수 연출

- 점수 증감 텍스트를 점수판 근처가 아니라 화면 중앙에 표시한다.
- 기존보다 기본 글자 크기와 이동 거리를 키운다.
- 점수 절댓값이 클수록 글자, 링, 파티클 수와 이동 반경이 커진다.
- 감점은 붉은색, 보너스는 앰버 계열을 유지한다.
- `prefers-reduced-motion`에서는 확대 연출을 제거한다.

## 검증

- GeoWeb 랜딩의 네 안내 문장, 버튼 문구, 버전 아코디언 확인
- 검색 패널이 대륙·대양 패널과 독립적으로 렌더되는지 확인
- `북한` 검색이 북한을 일반 결과로, `대한민구` 검색이 대한민국을 유사 결과로 반환하는지 확인
- 정확 결과가 유사 결과보다 앞서는지 확인
- 국가 변경·카드 닫힘 때 체제 팝업이 닫히는지 확인
- Spell Drill 랜딩과 버전 아코디언 확인
- 오답 감점이 10·20·30·40으로 증가하고 새 게임에서 초기화되는지 확인
- 점수 증감 텍스트가 중앙에 표시되고 규모가 점수에 비례하는지 확인
- 전체 Node 테스트와 Astro 빌드 통과
