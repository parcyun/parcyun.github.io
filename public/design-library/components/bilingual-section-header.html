Usage

1. .ps-header-bi CSS 블록 전체 복사
2. .ko (한글 메인) + .en (영문 캡스 서브) 만 교체

RULES:
- 한글 메인: Pretendard, font-weight 300, letter-spacing -1.2px (타이트)
- 영문 서브: Montserrat, ALL CAPS, font-weight 400, letter-spacing 1.8px (루즈)
- 영문 서브는 한글 번역이 아닌 "태그/마커" 역할
  예: "지금 가장 인기있는 강의" + "MOST POPULAR" (X "Most Popular Lectures")

WHEN TO USE:
- 모든 섹션 헤더 (cinematic mode 페이지의 기본 타이포 패턴)
- 강의·문서·아티클의 큰 블록 시작
- 카테고리·챕터·테마 구분

WHEN NOT TO USE:
- 작은 컴포넌트 내부 헤더 (h3 이하)
- 한글이 없는 영문 전용 페이지
- 단일 단어 강조 (대신 큰 hero title 사용)
