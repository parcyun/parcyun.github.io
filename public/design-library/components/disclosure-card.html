Usage

1. .disclosure-grid + .disclosure-item CSS 블록 + 작은 JS 스니펫 복사
2. 각 카드는 <button type="button" aria-expanded="false">
   - .di-num   짧은 번호 또는 카테고리
   - .di-label 메인 단어 (영문)
   - .di-body  펼침 시 내용

CRITICAL DETAILS:
- <button>을 사용해야 키보드 접근성 (Enter/Space로 토글)
- background: transparent + appearance: none 으로 브라우저 기본 회색 제거
  (이 reset이 없으면 카드가 밝게 보이는 버그 발생)
- aria-expanded 속성으로 상태 관리, JS는 토글만 담당
- max-height 트랜지션으로 펼침/접힘 부드럽게

WHEN TO USE:
- FAQ (자주 묻는 질문)
- 개념 인덱스 (학습자가 원하는 것만 펼침)
- 예시 프롬프트 모음 (5대 원칙 + 예시 패턴)
- 긴 콘텐츠를 압축 표시할 때

WHEN NOT TO USE:
- iframe 안에서 anchor 링크처럼 동작해야 할 때
  (anchor는 claude.ai 등에서 가로채임 — <button>이 안전)
- 펼침 콘텐츠가 너무 길 때 (별도 페이지로 분리)
- 사용자가 모든 콘텐츠를 봐야 할 때 (펼친 채 두기)

ACCESSIBILITY:
- aria-expanded 자동으로 스크린리더가 상태 안내
- Enter/Space 키 작동 (button 기본 동작)
- 토글 아이콘은 ::after로 추가하여 마크업 단순 유지
