Usage

1. 위 CSS 블록(.ending-credits ~ .ec-platform)을 통째로 복사
2. parcyun Cinematic Mode 토큰이 정의된 페이지에서 사용
3. ec-fade / ec-title / ec-meta dt·dd / ec-continue-* 내용만 교체
4. ec-continue href를 실제 다음 단계 링크로 지정

WHEN TO USE:
- 강의·문서·아티클 종결부 (학습 완료 후 다음 단계로 안내)
- 시리즈 콘텐츠의 챕터 마지막 페이지
- 영화 엔딩 크레딧처럼 "한 작품이 끝나고 다음으로 넘어가는" 인상이 필요할 때

WHEN NOT TO USE:
- 일반 CTA 버튼 자리 (과한 느낌)
- 라이트 모드 / 다른 브랜드 컬러 페이지 (parcyun Cinematic Mode 전용)
- 페이지 중간 섹션 (반드시 페이지 맨 끝)
