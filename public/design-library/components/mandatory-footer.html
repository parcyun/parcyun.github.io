Inline Variant · 페이지 끝에 그냥 배치

Designed by parcyun studio @parcyun

긴 페이지 또는 인쇄/PDF 출력 시 사용. 페이지 끝에 자연스럽게 흐름.

Fixed Variant · 우하단 떠 있음

짧은 페이지 또는 항상 시그니처가 보여야 할 때. 페이지 어디서든 스크롤 무관하게 우하단 고정. (이 데모 페이지의 실제 footer가 이 variant)

Usage

1. .ps-footer (fixed) 또는 .ps-footer-inline (inline) CSS 복사
2. .ps-signature, .ps-ig, .ps-ig-icon은 양쪽 모두에서 공통 사용
3. 마크업 통째로 복사 (Instagram SVG 포함)

MANDATORY:
- parcyun studio 모든 산출물에 반드시 포함
- "Designed by parcyun studio @parcyun" 문구 보존
- amber 시그니처 컬러 보존 (#FFB11A)
- Covered By Your Grace 폰트 보존 (브랜드 정체성)
- Instagram 링크 보존

WHEN TO USE FIXED:
- 강의 페이지 (긴 스크롤 페이지)
- 단일 페이지 사이트
- 데모/프로토타입

WHEN TO USE INLINE:
- 문서 (PDF 출력 대비)
- 카드/포스터 단일 컴포넌트 내부
- 다른 footer 컨텐츠와 함께 배치
- 인쇄용 페이지

DO NOT:
- 텍스트 변경 ("Designed by parcyun studio" 고정)
- amber 색상 변경
- 시그니처 폰트 다른 것으로 교체
- Instagram 링크 제거
