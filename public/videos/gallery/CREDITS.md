# Gallery preview sources

Every preview contains five two-second feature excerpts (10 seconds), muted and looped.
Browser-service footage is recorded in an isolated, signed-out browser. No player scores or rankings are fabricated for these recordings.

## ZoomIt

- Creator: Microsoft Sysinternals / Mark Russinovich.
- Official product page and embedded demonstration: https://learn.microsoft.com/en-us/sysinternals/downloads/zoomit
- Video metadata: https://learn.microsoft.com/api/video/public/v1/entries/31330ae9-ccc2-4001-a9ce-35dcbb8b5aa2
- Five brief excerpts show zoom, annotation, typing, recording and countdown. Original branding is retained. This is an independent educational product directory, not a Microsoft endorsement.
