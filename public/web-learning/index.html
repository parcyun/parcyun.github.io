로컬 학습실 열기 ↗

학습 서버를 실행한 컴퓨터에서 열어 주세요.
이 링크는 현재 기기의 로컬 서버로 이동합니다. 서버가 꺼져 있으면 연결되지 않아요.

다시 공부를 시작할 때

  1. Mac의 다운로드 / Codex / Projects / web-learning-lab 폴더를 여세요.
  2. 학습서버.command를 더블 클릭하세요. 실행 창은 열어 두세요.
  3. 위의 ‘로컬 학습실 열기’를 누르고 Codex 대화와 나란히 놓으세요.

학습 앱 소스는 비공개 저장소에 보관합니다. 이 공개 페이지는 실행 안내만 제공합니다. 현재는 단서 찾기, HTML 편집, HTTP 응답 관찰 미션을 제공합니다.

터미널로 실행하기
cd ~/Downloads/Codex/Projects/web-learning-lab
npm start

Node.js 22 이상이 필요해요. 외부 패키지 설치나 API 키는 필요하지 않습니다. 실행 중인 창에서 Control + C를 누르면 종료됩니다.
